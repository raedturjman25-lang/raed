## GitHub Pages (للمواقع الثابتة)

بعد تفعيل **GitHub Pages** من إعدادات المستودع (Settings → Pages → Source: GitHub Actions)،
سيتم النشر تلقائيًا عبر workflow:

- `.github/workflows/deploy-github-pages.yml`

### الرابط العام

لا تشارك رابط `http://localhost:4321` لأنه يعمل فقط على جهازك محليًا.
بعد النشر استخدم رابط GitHub Pages:

- `https://<username>.github.io/<repo>/`
  - أو `https://<username>.github.io/` إذا كان اسم المستودع `<username>.github.io`
